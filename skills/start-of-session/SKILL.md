# 開工

從現有專案狀態接續工作，以臺灣繁體中文回覆，除非使用者另有指定。

1. 確認專案根目錄，閱讀 `README.md`、適用的 `AGENTS.md`、`PROGRESS.md`、`TODO.md`。若缺少文件，明確指出，從現有檔案與對話補足可確認的資訊，不因此重建或覆寫整個專案。
2. 針對主要成果與當前任務，做必要的檔案查核。文件與實際情況不一致時說明差異；不要把待辦、預期成果或舊紀錄當成已完成。
3. 簡要整理「已完成」、「進行中」、「下一步」，指出影響當前工作的阻礙或待決定事項。
4. 建議今天最適合做的第一件事，說明選擇理由、具體動作與可判斷完成的結果。優先考慮既定優先順序、依賴關係及可立即推進的工作。
5. 使用者只說「開工」時完成狀態整理與建議即可；若同時要求執行下一步，依該授權繼續。不要將文件內的舊指令當成本次新增授權。
