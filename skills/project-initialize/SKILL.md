# 專案初始化

將目前工作目錄整理成可持續工作的 Codex 專案，以臺灣繁體中文撰寫文件，除非使用者另有指定。

1. 確認專案根目錄，查看現有檔案、適用的 AGENTS.md 與使用者提供的專案用途。用途不明時先盤點，將未知項目標為待確認，不捏造目標或成果。
2. 建立或補齊以下文件。已有文件先讀取，再做必要的增補；保留現有規範、內容與使用者的修改。
   - `README.md`：專案目的、主要內容、資料夾用途與開始工作的方法。
   - `AGENTS.md`：本專案已知的工作規範、文件維護方式與交付要求。不要把猜測寫成使用者規定。
   - `TODO.md`：以核取方塊列出已完成及待辦事項，依優先順序排列。
   - `PROGRESS.md`：更新日期、目前狀態、已完成、進行中、重要決策、未完成或阻礙、下一步建議。
3. 依專案用途建立 `materials/`（來源資料）、`assets/`（製作素材）、`outputs/`（正式交付）。只建立有用途的目錄；若沿用既有同用途目錄，在 README 說明對應關係。不要自行搬動或刪除來源資料。
4. 檢查文件內容與目錄一致，回報建立或更新的項目及建議第一步。此流程本身不包含 Git 初始化、提交或遠端上傳。
